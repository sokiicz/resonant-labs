What is Shikaku?

Shikaku is a Japanese logic puzzle. You get a grid with numbers scattered around it. Each number is a clue: it tells you the size of the rectangle that belongs to it. Draw that rectangle so it covers exactly that many cells — and make sure every rectangle touches exactly one number and every cell on the grid belongs to exactly one rectangle.

The rule is one sentence. The solving requires spatial reasoning, elimination, and a fair bit of patience on the harder boards.

How to play

  • Tap or click a numbered cell to start drawing a rectangle from it.
  • Drag to expand — the cell count updates live as you resize.
  • Release when the rectangle covers exactly the right number of cells.
  • Fill the whole grid without overlapping any rectangles to win.

No account, no install

Open the page in any browser and play. The whole game is a single HTML file — no server, no login, no app store. Works offline once loaded.

The idea

Shikaku is a puzzle format I've always liked — one rule, infinite variation. Most implementations online feel cluttered. I wanted something stripped back: just the grid, no sidebar noise, works on a phone without pinching. Built in a single session with Claude Code.

The constraints

No build step, no dependencies, no server — the entire game had to be a single HTML file that opens locally or via GitHub Pages without any setup. That constraint keeps the project permanently zero-maintenance and works offline once loaded.

Architecture

Single HTML file. No build step, no dependencies, no server. The puzzle is generated client-side, the game state lives in memory, and the canvas redraws on every frame update. Deploy is just pushing the file to a GitHub Pages repo.
